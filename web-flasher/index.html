Quick Connection Guide
  1. 1

    Connect USB-C Cable

    Plug the ESP32-C3 board into your computer with a high-quality USB data cable (ensure it is not a power-only charging cable).

  2. 2

    Click "Connect & Install Firmware"

    Your browser will display a security popup requesting access to the serial device (e.g. USB JTAG/serial debug unit or CP2102/CH340).

  3. 3

    Bootloader Mode (If device fails to respond)

    If the connection times out, hold down the BOOT (IO9) button, briefly press and release the RST button, then release BOOT. Click connect again.

  4. 4

    Erase & Flash

    Select "Install Smartcale ESP32". Choose "Erase device" for a fresh clean installation. The flash progress bar will take ~30 seconds.

Troubleshooting & USB Drivers
No serial port shows up in the browser popup

1. Cable Check: Many USB-C cables shipped with phones or power banks are power-only. Ensure you are using a data-capable USB cable.
2. USB Drivers: Depending on your ESP32 board chip: • ESP32-C3 Super Mini has native USB CDC (no extra drivers needed on macOS / Windows 10+).
• DevKits with CP2102: Install Silicon Labs CP210x Driver.
• DevKits with CH340 / CH341: Install WCH CH340 Driver.
3. Permissions on Linux: Run sudo usermod -a -G dialout $USER and reboot to permit non-root access to serial devices.

Error: "Failed to connect to ESP32" or "Timed out waiting for packet header"

The microcontroller is not in ROM Bootloader mode. Force manual bootloader mode:
1. Hold the BOOT (IO9) button on the ESP32-C3 board.
2. Press and release the RST (Reset) button once.
3. Release the BOOT button.
4. Click "Connect & Install Firmware" again.

Firmware successfully flashes, but display or load cell shows 0

Verify that your hardware pins match the pinout configuration:
• HX711: Data (DT) → GPIO 0, Clock (SCK) → GPIO 1
• Tare Tactile Button: GPIO 2 → GND
• OLED (SH1106 I2C): SDA → GPIO 8, SCL → GPIO 9
Open the Serial Monitor tab at 115200 baud to view startup self-checks and HX711 raw calibration ADC counts.
