Connection & Flashing Sequence

Follow these 4 physical steps to complete device installation without terminal tools.

  1. 1
    Connect USB Data Cable
    Plug the ESP32-C3 into your computer with a certified USB data cable (avoid power-only charge leads).
  2. 2
    Bootloader Mode
    If connection times out, hold BOOT (IO9), press and release RST, then release BOOT and retry.
  3. 3
    Select Port
    Click "Connect & Install Firmware". In the browser modal, pick the serial port (e.g. USB JTAG/serial debug unit).
  4. 4
    Clean Flash
    Select "Erase device" for clean initialization. The flashing process will complete in approximately 30 seconds.

Diagnostics & Hardware Troubleshooting

Common issues encountered during USB flashing and serial verification.

No serial port appears in the browser popup

1. Data Cable Check: Many USB cables packaged with power banks only deliver 5V power without D+/D- data pins. Ensure your cable supports data transfer.
2. USB Drivers: ESP32-C3 Super Mini boards feature native USB CDC and work without external drivers on macOS and Windows 11. Legacy DevKits with CP2102 or CH340 bridge chips require their respective USB UART VCP drivers.
3. Linux Permissions: Grant non-root user access to serial nodes via sudo usermod -a -G dialout $USER and log back in.

Error: "Failed to connect to ESP32" or "Timed out waiting for packet header"

The chip did not enter ROM Bootloader mode automatically. Perform manual bootloader strapping:
1. Hold the BOOT (IO9) button on the ESP32 board.
2. Briefly press and release the RST (Reset) button once.
3. Release the BOOT button.
4. Click "Connect & Install Firmware" again.

Firmware flashes successfully but weight output reads 0 or does not change

Verify load cell and display pinout connections:
• HX711 Data (DT) → GPIO 0, Clock (SCK) → GPIO 1.
• OLED Display: SDA → GPIO 8, SCL → GPIO 9.
• If testing prior to wiring modules, verify that ENABLE_MOCK_SCALE true is set in include/config.h to simulate weight telemetry.
